# Longitudinal plasma ATX(N) proteomic trajectories reveal early biomarker changes and biomarker-guided dietary prevention for Alzheimer’s disease and related dementias

Liu et al. Longitudinal plasma ATX(N) proteomic trajectories reveal early biomarker changes and biomarker-guided dietary prevention for Alzheimer’s disease and related dementias.

## Code

This repository contains the analysis code used in this study.

- **Analysis/**: Scripts for the statistical analyses described in the manuscript.
- **Figures/**: Scripts for generating the figures.

## Software requirements

The analyses were conducted using R (version 4.2.0) and Python (version 3.14.10).

The scripts require the corresponding R and Python packages and their dependencies. No separate software installation is needed.

## Running the code

Users should install the required packages and update the working directories and input/output paths in the scripts to match their local environment.
